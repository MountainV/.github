## 🧭 So arbeiten wir

- **Dokumentation zuerst** – was nicht dokumentiert ist, existiert nicht.
- **Issues für alles** – Idee, Bug oder Frage? → Issue aufmachen.
- **Branch → PR → Review** – kein Push direkt auf `main`.
- **Kleine Schritte** – lieber viele kleine PRs als ein Riesen-Brocken.

## 🤝 Mitmachen

1. Lies die [Doku](https://github.com/MountainV/docs).
2. Schau in die offenen [Issues](https://github.com/MountainV/docs/issues).
3. Nutz die Vorlagen beim Anlegen von Issues und PRs.
